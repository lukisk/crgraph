    Legend

    Lines — the arrow points to what is used

    • A uses B, unchanged
    • new: did not exist before this change
    • changed: existed before; this change adds or removes connections inside it
    • removed: no longer exists after this change
    • matched by name only (no exact import)
    • part of a finding (cycle, rule)

    Kinds — one line can bundle several; click it to see them

    depends on
    module dependency declared in a build file
    imports
    a file imports another file
    calls
    a function calls a function
    references
    code uses a type, property or constant
    inherits
    a type extends or implements another

    Boxes

    • added
    • modified
    • removed
    • moved
    • impacted: unchanged, but uses changed code
    • unchanged
    • module ⊃ file ⊃ class/function: double-click a box to open it
    • dashed frame: modules from the same top-level folder
